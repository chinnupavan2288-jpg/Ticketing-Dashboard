# Ticketing Dashboard

A standalone HTML/CSS/JavaScript ticketing dashboard that can be hosted on GitHub Pages.

## Calculation logic

- **Total Tickets = New Tickets + Pending**
- Completed, Development and Dev Support are displayed separately.
- Completed, Development and Dev Support are not added to Total Tickets.
- The dashboard includes search, filters, sorting, editing, deleting, adding members, adding tickets, CSV export and print snapshot.

## Run locally

Open `index.html` in a browser.

## Run on GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then click **Save**.
6. Open the generated GitHub Pages URL.
